# 网页翻译 · DeepSeek（Chrome 扩展）

使用 DeepSeek 将网页整体翻译为简体中文的 Chrome 扩展（Manifest V3）。核心特色：**按网页语境翻译**——每段文字会连同它在页面中的角色（按钮 / 导航 / 标题 / 正文 / 占位符 / 表头…）一起发给模型，按钮译成简短动词短语、正文译成流畅书面语，而不是千篇一律的直译。

## 功能特性

- **整页翻译**：点击弹窗按钮 / 右键菜单「翻译此页面为中文」/ 快捷键 `Alt+T`
- **语境感知**：自动识别元素角色（button / nav / heading / placeholder / th / label / tooltip…）与文本长度分类，随语境切换文风
- **属性翻译**：`placeholder`、`img alt`、`title`、按钮 `value` 一并翻译
- **保护不译**：`<code>` `<pre>` 代码块、脚本样式、已是中文的内容自动跳过；品牌名、URL、变量名等由模型按规则保留
- **原文对照**：支持「仅译文」与「原文+译文对照」两种模式，可一键恢复原文
- **译文缓存**：同一网址、模型及语境中的相同文本可命中本地缓存
- **懒翻译**：视口外的内容滚动到位时再翻译，长页面不卡顿
- **增量翻译**：MutationObserver 监听动态加载的内容（无限滚动、SPA 路由）自动翻译
- **失败重试**：自动指数退避重试，失败片段红色标记，可一键重试
- **接口权限**：默认访问 DeepSeek 官方域名；使用自定义 HTTPS 接口时，设置页会单独申请该域名权限。API Key 保存在本地，并在翻译请求中发送至所配置的接口

## 安装步骤

1. 打开 Chrome，访问 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录（`web-translator/`）
4. 点击工具栏扩展图标 → 「设置（API Key）」，填入你的 DeepSeek API Key
   - Key 获取：[platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
5. 可点击「测试连接」验证 Key 是否有效

## 使用方法

| 操作 | 方式 |
| --- | --- |
| 翻译当前页 | 点击扩展图标 → 「翻译本页」 |
| 翻译当前页 | 页面右键 → 「翻译此页面为中文」 |
| 翻译当前页 | 快捷键 `Alt+T` |
| 恢复原文 | 点击扩展图标 → 「显示原文」 |
| 重新翻译 | 点击扩展图标 → 「重新翻译」（跳过缓存，用于切换模型后重译） |

翻译进度显示在页面右下角的悬浮提示条中；未滚动到的内容会在你滚动接近时自动翻译。

## 工作原理

1. **按需注入**：点击翻译时才向当前标签页注入内容脚本（`activeTab`，不常驻、不申请全站权限）
2. **语境采集**：TreeWalker 遍历可见文本节点，为每段文字生成 `角色 + 长度分类` 的语境标签
3. **批量请求**：条目打包为 JSON 数组（默认 30 条/批，3 并发），经 Service Worker 调用 DeepSeek `chat/completions`（`response_format: json_object`，temperature 1.3）
4. **原位替换**：译文写回文本节点，保留首尾空白，不破坏 DOM 与样式

## 常见问题

- **提示 401**：API Key 无效，到设置页检查
- **提示 402**：DeepSeek 账户余额不足
- **提示 429**：请求过于频繁，扩展会自动退避重试；仍频繁可将「每次请求合并条数」调小或降低并发
- **提示后台无响应**：在 `chrome://extensions/` 核对“加载来源”是否为当前项目目录，并查看 Service Worker 是否显示“无效”；重新加载扩展后关闭旧设置页，再重新打开
- **有的内容没翻译**：代码块（`<code>/<pre>`）被有意保护；已是中文的内容跳过；Shadow DOM 内部内容暂不支持
- **chrome:// 页面、应用商店页面无法翻译**：浏览器限制，任何扩展都无法注入这些页面
- **本地 HTML 文件**：需在扩展详情页开启「允许访问文件网址」

## 已知限制

- Shadow DOM 内的文本、PDF、视频内嵌字幕暂不翻译
- 对照模式下原文以浅灰附注展示，极复杂内联结构中个别位置排版可能有细微变化
